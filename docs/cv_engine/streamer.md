# 📺 CV Engine: `streamer.py`

## What does `streamer.py` do?
This file contains the FastAPI router responsible for taking the video from the AI and putting it on the internet so the Laravel Dashboard can display it.

### How MJPEG works
Video is just a bunch of pictures shown very fast. `streamer.py` uses a web protocol called `multipart/x-mixed-replace`. 
It takes the JPEG pictures generated by the `Detector.get_frame_generator()` method and sends them down an HTTP connection one by one. The browser (like Chrome or Safari) knows how to read this special HTTP response and seamlessly replaces the previous picture with the new one, creating the illusion of a live video stream.

---

### 🧸 Explain Like I'm 5 (ELI5)
Imagine you have a flipbook. `streamer.py` is the person flipping the pages for you. The AI draws a picture on a page, and `streamer.py` instantly rips the page out and hands it to your web browser. Then it rips the next page out and hands it to your web browser. If it does this fast enough, it looks like a movie!

---

### 👩‍💻 How to Contribute
You rarely need to edit this file unless you are changing how the video is broadcasted over the network. If you ever wanted to upgrade the stream from MJPEG to a more complex format like WebRTC or HLS, this is where you would implement those endpoints.
